# User Management

## Create User

```bash
useradd john
```

## Set Password

```bash
passwd john
```

## Switch User

```bash
su - john
```

## Check User Information

```bash
id john
```

## Modify User

```bash
usermod -l devops john
```

## Delete User

```bash
userdel -r john
```

## Check Login History

```bash
last
lastlog
```
