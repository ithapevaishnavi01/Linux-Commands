# File Management Commands

## Create Directory

```bash
mkdir devops
mkdir -p project/src/config
```

## Create File

```bash
touch file.txt
touch file{1..10}.txt
```

## Copy Files

```bash
cp file.txt /tmp
cp -r folder1 folder2
```

## Move / Rename

```bash
mv file.txt /tmp
mv old.txt new.txt
```

## Delete

```bash
rm file.txt
rm -rf directory
```

## View Files

```bash
cat file.txt
less file.txt
head file.txt
tail file.txt
```
