# Networking Commands

## IP Information

```bash
ip addr
ifconfig
hostname
```

## Connectivity Testing

```bash
ping google.com
```

## DNS Commands

```bash
nslookup google.com
dig google.com
host google.com
```

## Download Files

```bash
wget https://example.com/file.zip

curl https://google.com
```

## Open Ports

```bash
netstat -tulnp

ss -tulnp
```
