## 🚀 Useful Linux Commands

### Check Current User
```bash
whoami
```

### Check Current Directory
```bash
pwd
```

### List Files
```bash
ls -la
```

### Check Disk Usage
```bash
df -h
```

### Check Memory Usage
```bash
free -m
```

### Check Running Processes
```bash
ps -ef
```

### Search Files
```bash
find / -name "*.log"
```

### Search Text
```bash
grep "error" logfile.log
```
